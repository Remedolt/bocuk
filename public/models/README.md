# Opsiyonel glTF modeller

Placeholder geometriyi değiştirmek için dosyaları buraya bırak. Oyun bunlar olmadan da tam çalışır.

| Dosya | Yerine geçer |
| --- | --- |
| `zombie.glb` | Prosedürel zombi (her spawn'da kopyalanır) |
| `weapon.glb` | Birinci şahıs tüfek |

Kafa vuruşu `Head` / `head` / `skull` adlı mesh arar. İsimli kafa yoksa modelde yaklaşık 1.34 m üzerindeki isabetler kafa sayılır.

Birimleri metre tut. Ayakta bir zombi kabaca 1.7 m olmalı. Silah kameraya bağlı görüş modeli olarak kullanılır.
