# BÖÖCÜK

**Oyna:** [https://remedolt.github.io/bocuk/](https://remedolt.github.io/bocuk/)

Üstten görünüm otomatik av. HTML5 Canvas, Vite, TypeScript. Sprite yoksa silahlar ve böcekler primitif çizilir.

## Kurulum

```bash
git clone https://github.com/Remedolt/bocuk.git
cd bocuk
npm install
npm run dev
```

`BAŞLA — TAM EKRAN` oyunu tam ekranda açar.

| Tuş | Aksiyon |
| --- | --- |
| `W A S D` | Hareket |
| Silahlar | En yakına otomatik ateş |
| `ESC` | Duraklat |
